# WoW Forever Macro Compendium

Static GitHub Pages site: one page per class with copy-paste macros distilled
from the [macro wiki](https://github.com/vocino/wow-macros/wiki).

- `index.html` — class grid (site front page).
- `classes/<class>.html` — one page per class (9 classes).
- `assets/style.css` — the only stylesheet. No JavaScript, no build step.

Preview locally by opening `index.html` in a browser. To publish: repo
Settings → Pages → Deploy from branch (`main`, root). `.nojekyll` is
already present so Pages serves the files as-is.
