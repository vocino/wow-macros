## Global rules (verbatim claims)

- 255 chars per macro (server-stored since 3.0.2). Overflow workaround: /click-chain across action-bar buttons.
- One GCD spell per press. A failed would-be-GCD /cast still blocks later lines (behavior since patch 2.0). Instant non-GCD spells chain freely (pre-2.3 needed /stopcasting between them, no longer).
- No wait/pause. A macro executes all lines in one frame. Long /run freezes the client.
- /script|/run: one line, semicolons as needed, tainted, locals discarded after the block. Cannot cast, use items, change action bar, or affect target. Patch 9.1.5 protected more APIs from /script.
- Cannot cast unattended (a button press is required), more than one GCD spell per press, or pause. Cannot auto-target another player's pet (own pet OK). File output restricted to saved variables only.
- Slots: General tab is account-shared, Character tab per character, 18-slot grid. Keep macro names unique (addon/macro references).
- Command names case-INsensitive. Multiple commands per macro, one per line. Secure commands accept [conditions] (comma = AND, semicolons = else-chain, conditions case-SENSITIVE, empty [] always true, trailing ";" creates a true empty clause). Only secure commands accept conditions: #show #showtooltip /assist /cancelaura /cancelform /cast /castrandom /castsequence /changeactionbar /clearfocus /cleartarget /click /dismount /equip(+) /equipslot(+) /equipset(+) /focus /petassist /petattack /petautocastoff /petautocaston /petdefensive /petfollow /petpassive /petstay /startattack /stopattack /stopcasting /stopmacro /swapactionbar /target /targetexact /targetenemy /targetfriend /targetfriendplayer /targetenemyplayer /targetlasttarget /targetlastfriend /targetlastenemy /targetparty /targetraid /use /usetalents(+) /userandom.
- Toggleable abilities toggle on /cast since 2.3.2. Prefix "!" forces cast-on (e.g. /cast !Stealth).

## Key verified syntax (detail pages)

- /cast [opts] spell|item|bagID slot|invSlotID, alias /spell, name conflict resolves to SPELL.
- /use [opts] item|item-link|bagID slot|invSlotID|spell, name conflict resolves to ITEM.
- /castsequence [opts] [reset=n/target/combat/shift/alt/ctrl] a1,a2,... One entry per press; a failed entry does NOT advance until it succeeds or resets.
- /castrandom and /userandom: random entry from a comma list. FLAG: still listed on Macro_commands but believed removed in the Cataclysm era; removal source not inspected.
- /stopmacro [options]: stops the innermost macro only.
- /script|/run: one line of Lua, tainted.
- /target|/tar [cond] name: nearest PREFIX match in ~90yd area of interest (longer in BGs). /targetexact: exact name only. /targetenemy|friend(|player) and /targetparty|raid usable ONCE per macro; optional 1 reverses.
- /focus [opts] unitId, bare form stores current target. /clearfocus clears.
- /click [opts] WidgetName [MouseButton, default LeftButton] [Down 1/true vs 0/false]. Ignored if the widget is busy.
- #show and #showtooltip: lowercase only, mutually exclusive (second ignored), accept conditionals.
- /equip <item>. /equipslot <slot#> <item> (slot repeated per conditional clause). /equipset <set>. Two same weapons for dual slots fail under /equip; use slots.
- /startattack [unit], key unit is target. /assist [name|unit]. /petattack [unit], key unit is pettarget. /petfollow cancels attack. /petmoveto shows a ground reticule. /petautocaston|off|toggle <spell>.
- /random [X] [Y]: 1-100, or 1-X, or X-Y.
- /changeactionbar n. /swapactionbar n m. /cancelform. /cancelaura <buff>.
